High resolution · tiled refine
Upscale above 1 generates a smaller base image, then refines it up to the requested size one tile at a time, so a large picture fits the same VRAM. The tile defaults to the largest that fits the preset budget, which is also the sharpest: each tile is composed as its own canvas, so smaller tiles mean more independently re-drawn detail. Needs a CUDA denoiser preset and native mode.
CUDA uses INT8 tensor cores; ROCm dequantizes row-INT8 weights for BF16 WMMA. Compare mode keeps the PyTorch reference unquantized.
