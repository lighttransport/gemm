2 · Edit optional, repeatable

Strength 1 edits through image conditioning; lower values stay closer to the current pixels. A box is enforced: outside it the object is kept pixel for pixel.

3 · Views optional

One sheet keeps the character, its proportions and details consistent across views; its front view becomes the current object and the views can feed posed multiview reconstruction.

Separate samples per view: good previews, but they drift from each other; use single-view reconstruction with them.

4 · 3D with Pixal3D

Single view is the safe default: separately generated views measured worse than the object alone (Chamfer 0.063 vs 0.024 against real views) because they drift. A turnaround sheet's views are consistent, so they can go to Pixal3D posed.
